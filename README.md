# ОсмотрЛист — демонстрационная версия

Интерактивный прототип электронного журнала осмотров детских и спортивных площадок.

## Возможности демо
- Реестр объектов с заданным пользователем интервалом проверок.
- Запись визуальных, функциональных и ежегодных основных осмотров (без автоматического расчёта отдельных графиков).
- Замечания и сроки их устранения.
- Выгрузка журнала в CSV, резервная копия в JSON, печать в PDF через диалог браузера.
- Демонстрационные вымышленные объекты и хранение данных только в текущем браузере.
- Проверка структуры импортируемых резервных копий.

## Ограничения (важно)
- Это **не готовый SaaS**: нет сервера, учётных записей, ролей и разграничения между компаниями.
- Вводите только учебные данные, без персональной и конфиденциальной информации.
- Очистка браузера может удалить данные. JSON-копия — локальный учебный экспорт, не серверный бэкап.
- Сроки, заданные в демо, **не являются нормативными**; отдельные графики по видам осмотров и оборудованию ещё не реализованы.
- Печать из браузера не является актом ежегодного основного осмотра и не гарантирует юридической значимости.
- Программа не заменяет профессиональную проверку оборудования.

## Запуск на JARVIS2
Откройте файл `index.html` в Google Chrome. Статическая версия не требует установки зависимостей.

## Исходный код
Демо использует нативные HTML/CSS/JS без внешних библиотек и запросов к закрытым API.
