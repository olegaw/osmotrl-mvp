# ОсмотрЛист — демоверсия
Интерактивный прототип электронного журнала осмотров детских и спортивных площадок.
## Что работает
- Реестр объектов и периодические проверки
- Запись осмотров и замечаний
- Сроки и статусы
- Выгрузка CSV, JSON и печать в PDF через системную печать
- Демонстрационные данные и локальное сохранение в браузере
## Ограничения
- Это **не рабочая SaaS-система**: нет серверного хранилища, авторизации, ролей и резервных копий на сервере.
- Данные доступны только в браузере и могут пропасть при его очистке.
- Не вводите персональные или конфиденциальные данные.
- Не используйте созданные в демо записи как официальные акты технического осмотра.
- Примерные сроки не являются нормативными требованиями, их нужно устанавливать в соответствии с эксплуатационной документацией и применимыми правилами.
## Запуск
Откройте `index.html` в браузере. Для публикации подходит GitHub Pages.
